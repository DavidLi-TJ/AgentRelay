AgentRelay

选择左侧一个会话，右侧逐字预览。

勾选要带走的条目，然后在接力页完成跨 agent 接力。

接力

把选中的会话写进目标 agent 的原生存储，接上就能继续干。三步：选源、选目标、执行。

1来源

2目标

3执行

Dry-run 会完整走一遍接力流程但不写盘：读源会话、按当前参数计算、合成目标格式，然后报告将写入的路径、条数、token 与转换损失。先用它确认，再开始接力（真实写入前会自动备份）。

活动记录

每一次接力、备份与设置变更都会记录在这里，用于追溯与排查。

诊断

各 agent 的存储健康、写前备份管理，以及可附在 issue 里的诊断包。

存储健康

备份管理

写入真实存储前的自动快照。还原前会先把当前状态再备份一份。

诊断包

不含会话内容：只有存储统计与最近日志，报 issue 时附上。
